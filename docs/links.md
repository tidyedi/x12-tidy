# External references

EDI resources worth keeping to hand — for looking up segment and element
definitions, code lists, and the shape of a transaction set. None of these is a
dependency; they are references.

## X12 standard

| Link | What it is |
| --- | --- |
| [ASC X12](https://x12.org/) | The standards body. Membership-gated for the full standard, but the site has the committee structure and release schedule. |
| [Stedi EDI Reference — X12](https://www.stedi.com/edi/x12) | Free, browsable segment / element / code-list reference for every X12 transaction set and version. The fastest way to look up what a segment expects. |
